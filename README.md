## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JavaScript (for customization)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/faiz-jihad/portfolio.git
cd portfolio
```

2. **Open in browser**
```bash
# Simply open index.html in your preferred browser
open index.html  # Mac
start index.html # Windows
```

3. **Customize**
- Replace `assets/img/` with your own images
- Update content in HTML sections
- Modify CSS variables for color scheme
- Update social media links

## 🔧 Customization Guide

### Change Colors
```css
:root {
  --gold: #your-color;
  --bg-dark: #your-dark-color;
}
```

### Add New Projects
```html
<a href="your-github-link" target="_blank" class="project-link">
  <div class="project-item">
    <div class="project-image"><img src="your-image.jpg" alt="Project"></div>
    <div class="project-content">
      <h3>Project Title</h3>
      <p>Description</p>
      <div class="project-tech">
        <span>Tech1</span>
        <span>Tech2</span>
      </div>
    </div>
  </div>
</a>
```

### Update Organization
```html
<div class="org-card">
  <div class="org-icon">
    <span class="iconify" data-icon="mdi:your-icon"></span>
  </div>
  <h4>Organization Name</h4>
  <div class="org-position">Your Position</div>
  <!-- Add achievements -->
</div>
```
